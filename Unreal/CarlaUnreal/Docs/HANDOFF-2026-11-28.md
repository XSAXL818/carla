## 一、现在怎么用

| 动作 | 做法 |
|---|---|
| 进配置界面 | 直接启动（`UnrealEditor.exe <uproject> -game …`），默认地图已是入口关卡 `L_TestPlatformEntry`，面板自动出现、后端自动拉起（可见 Windows Terminal 窗口） |
| 看后端日志 | 终端窗口标题固定为 `CARLA TestPlatform Backend`，实时输出 uvicorn 访问日志 |
| 停后端 | 关掉那个终端窗口即可（不会自动重启） |
| 重新起后端 | 面板离线卡片上的「启动后端」按钮，或控制台命令 `TestPlatform.StartBackend` |
| 安静浏览其他地图 | 直接在编辑器里打开 Town01–07 等关卡，**不会有面板** |
| 想在某张非入口图上强制看面板 | 加 `-TestPlatformForceUI`，或控制台 `TestPlatform.Panel 1` |

入口白名单由 `Config/DefaultGame.ini` 的 `[/Script/TestPlatform.TestPlatformSettings] EntryMaps` 控制，默认只有入口关卡。

## 二、这一轮改了什么

1. **CEF 清理**：删掉 `WebBrowserWidget` / `WebBrowser` 依赖、两处 HTML 原型、相关注释与文档段落。
2. **插件 → 工程模块**：`Plugins/TestPlatform` 迁为 `Source/TestPlatform`（代码）+ `Source/TestPlatform/Platform`（后端、工具、图、文档），`.uproject` 注册模块，3 处硬编码路径改正。
3. **面板状态真实化**：顶栏连接状态改读 `/health` 的 `carla.connected`（含三种状态与同源着色的方点、真实探测地址、地图加载期间显示“未知”）；右栏两处被裁切的提示改为自动换行。
4. **后端可见窗口**：由隐藏进程改为 Windows Terminal 窗口，关窗即停、编辑器退出不杀后端、无自动重启、失败可降级为普通控制台。
5. **面板自动接管 + 启动按钮**：自启后端后无需点击即可加载目录（实测 0.5–0.9 s）；离线卡片新增「启动后端」。
6. **同步模式看门狗**：`carla.SyncCueGrace`(60 s，仅无客户端时生效) + `carla.SyncCueCeiling`(300 s，无条件下限)；两个阈值设 0 可关闭。客户端暂停不再被误踢，打 tick 的客户端死掉后编辑器必定在 ceiling 内恢复。
7. **入口关卡**：新增 `Content/TestPlatform/`（平台资产归口）与空壳关卡 `Maps/L_TestPlatformEntry`（含一个 PlayerStart 与零道路 OpenDrive）；`GameDefaultMap`/`EditorStartupMap` 指到它，`ServerDefaultMap` 未动；面板按“本次运行起始地图”判定是否出现。
8. **文档与依赖**：`architecture.md` 全面对齐代码，新增 `requirements.txt`，补 `CHANGELOG.md`。

## 四、已知限制（有意保留，不是待修 bug）

- 面板可见性按“**本次运行起始地图**”判定，并有“离开入口流程后不再重新武装”的规则。因此：从入口关卡启动后在同一进程里手动 `open Town05`，面板会关闭且不会因再回入口图而恢复；独立在 Town05 上启动的进程从不显示面板。这是为了兼容后端在同一进程里 `load_world` 的机制。
- 同步看门狗的客户端存活判定是**端口级**的（任何一条 ESTABLISHED 都算“有人”），因此 grace 只在完全无连接时生效；保证恢复靠 ceiling（默认 300 s）。非 Windows 平台无此存活判定，只有超时。
- UMG 迁移已评估后**撤销**（见 `architecture.md §15`）：界面迭代由 agent 承担，编译等待不计入人的时间。
